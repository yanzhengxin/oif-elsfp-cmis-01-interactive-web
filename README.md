# OIF-ELSFP-CMIS-01.0 · 主机怎么管 ELSFP

一份**单文件、零外部依赖**的交互式网页，把 OIF-ELSFP-CMIS-01.0（ELSFP 的 CMIS 管理接口实施协议，2024-09-04 首次发布，34 页）里「主机如何管理一台外置激光」这条主线讲清楚。

## 怎么读

- **首屏 30 秒版**：一张主机 ↔ ELSFP 的结构图，一句话说清这份规范的全部。
- **7 个场景**：资源模块 → 内存与 bank 机制 → 通告与能力 → 阈值/告警/警告/掩码 → lane 使能与状态机 → 输出光纤检查 → 监视量与固件升级。
- **点角标看原文**：文中每个关键数字旁的角标可点开，显示 PDF 原文页码 + 英文原句 + 中文转述，共 76 条逐字引文，全部经脚本对 PDF 文本层校验命中。
- **4 处「先猜再看」**、**结尾 3 题自测**、**U16 原始值换算器**、明暗主题与字号记忆。

## 主视觉

1. 主机 ↔ ELSFP 双线接口结构图（bank 与 lane 芯片组）
2. 字节 42 的四档模块分类（ELSFP 落在第二档「仅 MSM」）
3. Page 1Ah / 1Bh 分区布局（标出 banked 与不分 bank 的区段）
4. 告警 OR 汇总结构（汇总位不是 latched，也不是 COR）

## 已知的一处原文矛盾

1Bh 的 lane 输出光功率监视量：按原文给的 LSB = 10 µW 推算，65535 × 10 µW = 0.65535 W，但原文写的是 6.5535 W，同时给出的「−40 … +38.16 dBm」也与 0.65535 W 不自洽。页面照实引用原文并单独标出「推算」的自洽值，实测请以厂商数据手册为准。
